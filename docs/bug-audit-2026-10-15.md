# Проверка существующей функциональности — 15 октября 2026

Область: Dashboard, Meta Lab, Steam-сессии и удаление аккаунта, ошибки API, PostgreSQL, мобильная навигация и сборка. Новые продуктовые разделы и Railway не подключались.

## Исправленные проблемы

| Проблема | Исправление и подтверждение |
|---|---|
| Поиск оставлял ID другого профиля при переходах назад/вперёд | Строка поиска и сообщение валидации синхронизированы с URL. Browser test проверяет оба направления истории. |
| Выход из демо сохранял введённый ID | Поле сбрасывается при смене режима. Проверено в браузере. |
| Фильтры 7/30 дней в демо давали пустую историю после устаревания фикстуры | Только в демо период отсчитывается от последнего матча выборки, с явной подписью. Реальные матчи фильтруются относительно текущего времени. |
| Неизвестный lobby_type попадал в «Остальные» | Неизвестные режимы исключены из определённых категорий и остаются во «Все режимы». |
| Escape закрывал подтверждение во время удаления аккаунта | Пока запрос выполняется, отмена заблокирована всеми способами. После серверной ошибки отмена снова доступна. |
| Закрытое мобильное меню оставалось доступным клавиатуре | Закрытая панель inert; открытая удерживает фокус и блокирует прокрутку страницы. Escape возвращает фокус на кнопку; переход и desktop resize закрывают меню. |
| Переход между страницами сохранял прокрутку предыдущей страницы | При смене пути прокрутка сбрасывается вверх. |
| Пул героев в другой вкладке оставался устаревшим | Обрабатываются storage events и очистка хранилища. Повреждённые/повторные/небезопасные числовые ID отбрасываются. Проверен настоящий второй tab в одном browser context. |
| JSON null от прокси вызывал TypeError, HTML вместо JSON — непонятный SyntaxError | API adapter выдаёт понятные сообщения. Отмена запроса сохраняет исходную семантику AbortSignal. |
| Повреждённая строка матча могла вызвать AttributeError и HTTP 500 | Тип строки проверяется до обработки. Отрицательные, boolean и нецелые счётчики, неверные ID/даты отклоняются с upstream_format. Нули и null остаются различимы. |
| Некорректный player_slot мог быть засчитан победой/поражением | Только слоты 0…4 и 128…132 участвуют в определении стороны; остальные результаты неизвестны. |
| Повторы матчей и игнорирование upstream limit искажали выборку | Дубликаты отклоняются, выборка ограничена последними 100 матчами после сортировки. |
| Неожиданный формат справочника попадал в ответ без проверки | Проверены ID, имена, пути картинок, уникальность героев. Некорректный ответ возвращает контролируемую ошибку. |
| Разрыв HTTP-протокола выходил за обработку сетевых ошибок | TransportError обрабатывается с теми же ограниченными тремя попытками. |
| Медленная загрузка одного профиля задерживала даже готовый кэш других данных | Cache hit проверяется до lock; повторная проверка внутри lock сохраняет coalescing промахов. Async test удерживает медленный запрос и проверяет независимость готового результата. |

Страница конфиденциальности дополнена описанием localStorage пула, синхронизации и отличия локального списка от серверного аккаунта.

- `RUN_POSTGRES_TESTS=1 python -m pytest -q`: **93 passed**, в том числе жизненный цикл сессии, Steam assertion/state/replay, origin/cookies, удаление и параллельный первый вход на PostgreSQL. Одно известное предупреждение совместимости Starlette TestClient/HTTPX, без падений.

- Локальный preview пересобран, миграции применены, серверы перезапущены с исправлениями. Проверки с настоящим источником выполнялись на новом сервере.
- Пользовательские файлы резервных копий и очистки не изменялись; секреты и локальная среда не включаются в исходники.

Локальный браузерный прогон использует Chromium с desktop и мобильным viewport; отдельные Safari/Firefox и физический телефон не проверялись. Проверки покрывают найденные дефекты и основные сценарии, но не доказывают отсутствие любых ошибок.
